# 🏥 roszdrav_checker — Проверка медицинских лицензий (Росздравнадзор)

Python-скрипт для автоматизированной массовой проверки наличия медицинских лицензий у организаций (в том числе детских лагерей) по ИНН. Использует библиотеку **Playwright** для работы с открытым реестром лицензий Росздравнадзора.

## 🚀 Возможности

✅ **Массовая обработка**: Загрузка списка ИНН из CSV-файла.  
🔄 **Устойчивость**: Возможность остановить и возобновить проверку с последнего сохраненного результата.  
🛡 **Имитация пользователя**: Использование реального браузера для обхода простых защит.  
📊 **Отчет в реальном времени**: Результаты сохраняются в `report_licenses.csv` сразу после каждой проверки.  
⚡ **Гибкие настройки**: Легко менять задержки, режим видимости браузера и пути к файлам.

## 🛠 Установка

Для работы требуется Python 3.8+ и установленная среда разработки.

1.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Установите браузер Chromium для Playwright:**
    ```bash
    playwright install chromium
    ```

## 📝 Использование

1.  Подготовьте файл со списком ИНН.
    По умолчанию скрипт ожидает файл `ИНН организаций отдыха детей и их оздоровления - Лист1.csv` в корне папки. Формат: обычный CSV, где в первом столбце указаны ИНН.

2.  **Запустите скрипт:**
    ```bash
    python roszdrav_checker.py
    ```

3.  **Результат:**
    В папке появится файл `report_licenses.csv`, который можно открыть в Excel.

## ⚙️ Настройки

Настройки находятся в начале файла `roszdrav_checker.py`:

*   `INPUT_FILE`: Путь к входящему CSV-файлу с ИНН.
*   `OUTPUT_FILE`: Путь к файлу, куда будет сохраняться отчет (по умолчанию `report_licenses.csv`).
*   `HEADLESS`: 
    *   `False` — Браузер открыт (удобно для первой отладки).
    *   `True` — Браузер скрыт (работает быстрее, рекомендуется для массовой проверки).
*   `DELAY`: Пауза между запросами в секундах (рекомендуется 1.5–2.5 для снижения нагрузки на сервер).

## 📂 Структура проекта

*   `roszdrav_checker.py` — Основной исполняемый скрипт.
*   `requirements.txt` — Список библиотек.
*   `.gitignore` — Файл для игнорирования временных данных и отчетов в Git.
*   `report_licenses.csv` — Файл с результатами (генерируется автоматически).
